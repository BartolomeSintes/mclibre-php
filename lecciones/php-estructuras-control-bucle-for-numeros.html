Generación de secuencias numéricas

Secuencias numéricas

  • Variable de control
  • Fórmula
  • Cálculo iterativo

En la lección Bucles for se explica la sintaxis del bucle for. En esta lección se explican tres maneras de utilizar un bucle for para generar una secuencia de números en sucesión aritmética.

En una sucesión aritmética, la diferencia entre dos términos consecutivos es siempre la misma. Por ejemplo, en la sucesión 3, 7, 11, 15, 19, cada número se obtiene sumando 4 al anterior.

Los tres ejemplos de esta lección imprimen esa misma sucesión. En el primero se imprime la variable de control del bucle, en el segundo se calcula cada número mediante una fórmula y en el tercero se utiliza una variable auxiliar que se modifica en cada iteración.

Los tres métodos permiten generar también sucesiones decrecientes. En ese caso, se resta la diferencia en el primer y tercer método, o se utiliza un coeficiente negativo en la fórmula. En el primer método también hay que adaptar la condición de continuación para que el bucle termine.

Puede practicar estos tres métodos en los ejercicios de bucles for (0).

Imprimir la variable de control

La primera manera consiste en hacer que la variable de control tome los valores de la sucesión. En el cuerpo del bucle se imprime directamente esa variable.

En el ejemplo siguiente, la variable $i empieza valiendo 3 y aumenta de 4 en 4 mientras sea menor o igual que 19.

Ejemplo de variable de control

<?php
for ($i = 3; $i <= 19; $i = $i + 4) {
    print "$i ";
}
?>

Calcular cada término mediante una fórmula

La segunda manera consiste en utilizar la variable de control para contar las iteraciones y calcular el número que se imprime mediante una fórmula.

En el ejemplo siguiente, la variable $i toma los valores 0, 1, 2, 3 y 4. En cada iteración se imprime el resultado de la expresión 4 * $i + 3.

Para obtener la fórmula:

  • Se calcula la diferencia entre dos términos consecutivos: 7 - 3 = 4.
  • Se multiplica la variable de control por esa diferencia: 4 * $i.
  • Se suma el primer término de la sucesión: 4 * $i + 3.

Esta fórmula supone que la variable de control empieza en 0 y aumenta de uno en uno. Así, para $i igual a 0 se obtiene 4 * 0 + 3 = 3, para $i igual a 1 se obtiene 4 * 1 + 3 = 7, etc.

Ejemplo de fórmula

<?php
for ($i = 0; $i < 5; $i++) {
    print 4 * $i + 3 . " ";
}
?>
3 7 11 15 19

Calcular cada término a partir del anterior

La tercera manera consiste en guardar el término de la sucesión en una variable auxiliar. En cada iteración se imprime esa variable y después se modifica su valor para obtener el siguiente término. Este procedimiento se denomina cálculo iterativo.

En el ejemplo siguiente, la variable de control $i cuenta las cinco iteraciones. La variable auxiliar $x empieza valiendo 3 y aumenta en 4 después de imprimir cada número.

Ejemplo de cálculo iterativo

<?php
$x = 3;
for ($i = 0; $i < 5; $i++) {
    print "$x ";
    $x = $x + 4;
}
?>
